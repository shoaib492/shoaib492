## About

Cloud and DevOps engineer with hands-on experience in **Python automation** and **multi-cloud environments** across **AWS, Azure, and Google Cloud**. I build CI/CD pipelines, containerize workloads with Docker, and manage cloud infrastructure as code with Terraform.

My engineering approach is rooted in root-cause analysis and a product mindset. I focus on systems that are secure by default (least-privilege IAM, hardened Linux servers), observable (Dynatrace, Splunk, CloudWatch), and repeatable (automation and documented runbooks).

I also have full-stack development exposure through React.js, PHP, and MySQL, which helps me understand application delivery across the development and infrastructure lifecycle.

- Automating server provisioning, backups, and routine operations with Python and Bash.
- Designing secure AWS networking with VPCs, subnets, security groups, and IAM.
- Monitoring and troubleshooting cloud workloads.
- Building CI/CD pipelines using Jenkins and GitHub Actions.
- Documenting reusable operational runbooks.
- Supporting cloud migration cutovers and incident investigation.

**Open To:** Cloud Engineer, DevOps Engineer, Site Reliability Engineering, and Platform Engineering opportunities.
