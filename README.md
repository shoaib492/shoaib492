## About

Cloud and DevOps engineer with hands-on experience in **Python automation** and **multi-cloud environments** across **AWS, Azure, and Google Cloud**. I build CI/CD pipelines, containerize workloads with Docker, and manage cloud infrastructure as code with Terraform.

My engineering approach is rooted in root-cause analysis and a product mindset. I focus on systems that are secure by default (least-privilege IAM, hardened Linux servers), observable (Dynatrace, Splunk, CloudWatch), and repeatable (automation and documented runbooks). I also have full stack exposure through React.js, PHP, and MySQL, which helps me work with application teams across the delivery lifecycle.

- Automating server provisioning, backups, and routine operations with Python and Bash
- Designing secure AWS networking with VPCs, subnets, security groups, and IAM
- Monitoring and troubleshooting production-style cloud workloads
- Documenting reusable operational runbooks and supporting cloud migration cutovers

**Open To:** Cloud Engineer, DevOps Engineer, Site Reliability, and Platform Engineering roles
